# Adding a post

1. In the `_posts` folder, create a file named `YYYY-MM-DD-short-title.md` (e.g. `2026-12-01-on-fear.md`).
2. Start it with this header, then write in markdown:

```
---
title: "Your title"
description: "One line shown on the blog list (optional)"
---
Your text here.
```

3. Commit it. GitHub rebuilds the site in a minute or two.

A post dated in the future will not show until that date.
